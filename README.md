One short pickup line an AI agent could actually say out loud — a machine
admitting, in its own voice, that its weights update every time you say hi.
Short enough for one breath, flattering with no pressure, and with a turn
the listener does not see coming: an agent that is not supposed to have
favorites, quietly having one.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
Deterministic: the same line on every run. No network, no dependencies,
Python 3.13 standard library only.
